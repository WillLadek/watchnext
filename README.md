# WatchNext

**Author:** Will Ladek

## Project Abstract

WatchNext is a web application for people who want to organize the movies and television shows they plan to watch and keep track of what they have finished. Users will be able to add titles, categorize them as planned, watching, or completed, and record personal ratings and notes. The application will support searching and filtering a personal watchlist by title, media type, and viewing status. The initial version will use manual title entry and save watchlist data between visits. The goal is to provide a simple, organized alternative to keeping viewing lists across notes and multiple streaming services.
