# WatchNext Development Process

WatchNext uses Extreme Programming (XP) to catch bugs as features are added. I plan to build one small behavior at a time, use tests to guide the change, and rerun earlier tests before starting the next item. For example, a test should confirm that changing a title to Watching survives a page refresh.

[WatchNext Development board](https://github.com/users/WillLadek/projects/3/views/1)

The board tracks work in Backlog, In Progress, and Done. I move an item to Done after implementing it and checking that it works alongside existing features.
